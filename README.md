# Open Power Control

Open Power Control (OPC) is a custom vehicle power-control platform built around multiple Open Power Control Modules (OPCMs), an adaptable operator HMI, and a dedicated CAN bus.

The first installation, **Clifford**, controls auxiliary and warning lighting, compressor-related equipment, and other accessories in a Toyota 4Runner.

## Planning status

The system is currently being specified through the [Wayfinder decision map](.scratch/pcm-hmi-system/map.md). Canonical project terminology lives in [CONTEXT.md](CONTEXT.md).

Firmware, hardware documentation, configuration, tests, and tools will be added as the map's design decisions are resolved.
