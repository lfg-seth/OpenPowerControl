# Specify the accessory CAN contract

## Question

What versioned CAN 2.0 contract should connect PCMs and HMIs on the dedicated bus?

Decide standard versus extended identifiers, bitrate, priority/arbitration strategy, node addressing, discovery, heartbeats, capabilities, commands, acknowledgements, desired versus actual state, telemetry, faults, configuration, time/synchronization, freshness, duplicate handling, compatibility rules, and bus-load budgets. Treat the existing 29-bit layout and 250 kbps implementation as evidence to evaluate, not an irreversible decision.
