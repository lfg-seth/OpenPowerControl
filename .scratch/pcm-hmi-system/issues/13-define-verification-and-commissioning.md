# Define verification and commissioning

## Question

What evidence is required before firmware may control real vehicle loads, and what staged process moves from host tests to simulated CAN, bench hardware, current-limited loads, installed commissioning, and regression checks?

Include protocol conformance, fault injection, reset/brownout behavior, output-safe startup, timing and synchronization, overcurrent/thermal response, configuration mismatch, stuck inputs, bus failure, logs/diagnostics, per-board acceptance records, and a rollback/recovery path.
