# Model vehicle functions and operator intent

## Question

What vehicle-level functions must the system expose independently of physical channels, and how should each respond to operator intent?

Define the first installation's ordinary accessories, compressor functions, steady lighting, mutually exclusive high/low modes, coordinated multi-output functions, warning-light modes, priorities, cancellations, and interlocks. Include concrete edge cases such as changing a three-position switch while a pattern is active, rebooting one PCM mid-pattern, and two controls requesting incompatible states.
