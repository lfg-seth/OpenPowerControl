# Define the living documentation set

## Question

Which version-controlled documents and generated views must exist so a future maintainer can understand, build, wire, configure, flash, test, install, operate, and troubleshoot the system—and what workflow keeps them synchronized with code and hardware revisions?

Cover system context, glossary, safety model, architecture decisions, PCB/BOM/schematic and connector references, pin/channel maps, CAN contract, configuration reference, build/flash instructions, bench procedures, installation records, operator behavior, diagnostics, and change/release history.
